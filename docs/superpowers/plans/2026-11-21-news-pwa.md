# News PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A personal, premium-looking news PWA: category + country filtering over RSS feeds fetched every 30 min by GitHub Actions, hosted on GitHub Pages.

**Architecture:** A Node script fetches and normalizes RSS feeds into `public/feeds.json`. A static Vite/React app loads that file, filters client-side, and a service worker caches it for offline use. A scheduled GitHub Action rebuilds and deploys to Pages.

**Tech Stack:** Vite, React, TypeScript, vitest, vite-plugin-pwa, rss-parser, GitHub Actions/Pages.

**Spec:** `docs/superpowers/specs/2026-11-21-news-pwa-design.md`

## Global Constraints

- Installable on iPhone via Safari "Add to Home Screen" (HTTPS, manifest, icons incl. 180x180 apple-touch-icon).
- Dark by default, light mode supported.
- Link out to original articles; never store full article text (snippet max 200 chars).
- ~5-8 outlets per category; `country` = outlet's country.
- GitHub account for this project: `muaawia` ONLY. Never use `marshad-coursera`. Confirm `gh auth status` shows `muaawia` active before any `gh`/git push. Ask the owner before creating or pushing the repo.
- No accounts, search, push notifications, or backend.

## Review Focus

- Feed that times out or returns invalid XML: fetch job skips it, others still publish.
- Article with no image: card renders a styled fallback, no broken image.
- Same story from two outlets (same link): shown once.
- Country/category combination with zero stories: friendly empty state, not a blank screen.
- Offline with no cached `feeds.json` yet: clear "connect to load stories" message.

## File Structure

- `scripts/sources.json`: outlet list (name, url, category, country).
- `scripts/fetch-feeds.ts`: fetch, normalize, dedupe, write `public/feeds.json`.
- `src/lib/types.ts`: `Article`, `Category`.
- `src/lib/filter.ts`: pure filtering/sorting.
- `src/components/`: `Feed`, `ArticleCard`, `HeroCard`, `CategoryChips`, `CountryPicker`.
- `src/App.tsx`, `src/styles.css`: layout, theme tokens.
- `.github/workflows/deploy.yml`: scheduled build + Pages deploy.

```ts
type Category = 'world'|'politics'|'sport'|'science'|'tech'|'business'|'health'
```
